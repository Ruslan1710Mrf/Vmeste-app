## 3. Тест на iPhone (два аккаунта: A — iPhone с TestFlight, B — любой другой)
Разрешение:
- [ ] A отправляет первое сообщение → появляется системный запрос уведомлений → «Разрешить».
- [ ] В Firestore `users/{A}/private/push.tokens` появился `ExponentPushToken[...]`.

Сообщения:
- [ ] B пишет A, приложение A свёрнуто → пуш с именем B и текстом. Нажатие открывает чат.
- [ ] B пишет 3 сообщения подряд → один пуш (серия — не чаще раза в минуту).
- [ ] Чат с B открыт на A → новое сообщение без баннера.

Комментарии:
- [ ] B комментирует пост A → пуш + запись в «Уведомлениях», счётчик непрочитанных. Нажатие → пост.
- [ ] «Прочитать все» сбрасывает счётчик.

События:
- [ ] A создаёт событие с датой «<завтра> · <время через 25 ч>», B записывается.
      В Firestore у события есть `startsAt`, `attendees` = 2.
- [ ] Через ~1 ч у B пуш «Напоминание: … Начало через 24 ч» (функция ходит раз в 15 мин).
- [ ] Событие с датой «в субботу вечером» создаётся без ошибок (просто без `startsAt`).

Правила:
- [ ] A блокирует B → сообщения/комментарии B больше не дают пушей A.
- [ ] Настройки → выключить «Push-уведомления» → пуши не приходят; включить — снова приходят.
- [ ] Выключить «Напоминания о событиях» → напоминаний нет, сообщения приходят.
- [ ] Выход из аккаунта A → пуши для A на этот телефон не приходят.
- [ ] Удаление тестового аккаунта → в Firestore нет `users/{uid}/notifications`, `private/push`, записей в `events/*/attendees`.

Общее:
- [ ] Тёмная и светлая тема на экране «Уведомления».
- [ ] Фильтр мата в посте/чате работает как раньше; жалоба и блокировка работают.
- [ ] Production-сборка: пуш реально пришёл (проверка aps-environment = production).
